## 💻📝 Atelier Flexbox — “Cartes d’entretien de plantes”  
### 💻📝 Flexbox Workshop — “Plant Care Cards”

### 🎯 Objectif / Objective
Créer une **page de cartes de plantes** en utilisant **uniquement Flexbox**.  
L’objectif est de comprendre :
- l’alignement (`justify-content`, `align-items`)  
- la direction (`flex-direction`)  
- la distribution (`flex-wrap`, `gap`)  
- le comportement responsive d’une grille sans Grid ni position absolue  

Create a **plant card page** using **only Flexbox**.  
You’ll learn to control alignment, direction, wrapping, spacing, and responsive behavior — without Grid or absolute positioning.

---

### 🧩 Ce que vous allez faire / What to do
Construire une **page catalogue** présentant plusieurs plantes.  
Chaque carte contiendra :
- 🌿 une image  
- 🏷️ un titre  
- ⚙️ un bloc “spécificités” (ex : arrosage, lumière, température…)  
- ✏️ une courte description  
- 🔗 un lien ou bouton optionnel  

Build a catalog page featuring multiple plants.
Each card will include:
- 🌿 an image
- 🏷️ a title
- ⚙️ a “Specifics” block (e.g., watering, light, temperature)
- ✏️ a short description
- 🔗 an optional link or button

You’ll build a **catalog page** showing multiple plants.  
Each card should include: image, name, details, description, and optionally a link/button.

---

### 🧱 Contraintes / Constraints
- ❌ Pas de CSS Grid  
- ❌ Pas de frameworks (Bootstrap, Tailwind, etc.)  
- ❌ Pas de position absolue  
- ✅ Utiliser uniquement **Flexbox** pour l’agencement  
- ✅ HTML simple, accessible et bien structuré  

- 🧱 Constraints
- ❌ No CSS Grid
- ❌ No frameworks (Bootstrap, Tailwind, etc.)
- ❌ No absolute positioning
- ✅ Use Flexbox only for layout
- ✅ Simple, accessible, well-structured HTML

---

### 📐 Propriétés Flexbox à utiliser / Flexbox properties to use
`display: flex` • `flex-direction` • `flex-wrap` • `gap`  
`justify-content` • `align-items`

*(Les propriétés avancées `flex-grow`, `flex-shrink`, `flex-basis` pourront être vues plus tard.)*

---

### 📱 Responsive design (BONUS)
- **Mobile-first** recommandé  
- Points de rupture conseillés : `1024px`, `768px`, `480px`  
- Les cartes doivent se réorganiser sans déborder  

- **Mobile-first** recommended.  
- Suggested breakpoints: `1024px`, `768px`, `480px`.  
- Cards must adapt fluidly without overflow.
(Advanced properties like flex-grow, flex-shrink, flex-basis can be covered later.)
